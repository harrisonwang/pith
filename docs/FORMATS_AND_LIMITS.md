# 格式与限制

以下内容适用于 spoor `v0.13.0`，说明各格式能读出什么、可能漏掉什么。

## 默认限制

`spoor-core` 每次最多处理 64 MiB；CLI 一次处理多个文件时，这些文件共用 64 MiB。CLI 总输出默认不超过 256 KiB。CSV、TSV 和 XLSX 默认每张表返回前 100 条数据行。

这些限制不等同于程序的实际内存占用。处理来源不明的文件前，请同时阅读[安全说明](../SECURITY.md)。

## 文档格式

| 格式 | 能读出什么 | 限制 |
| --- | --- | --- |
| PDF | 文字层、分页、书签标题、网页和邮件链接；会尝试按文字位置调整双栏阅读顺序，合并明显的跨行断词，并去掉重复页眉页脚；需要时可以返回页码和近似坐标 | 不做 OCR；复杂多栏和表格的阅读顺序可能不准；没有书签时不猜标题；坐标只适用于能直接读出的文字行 |
| DOCX | 标题、段落、粗体和斜体、列表、链接、脚注、小型表格、修订中新增的文字，以及可以提取的图片链接 | 不保留样式和版面；复杂编号、合并表格、图表、评论和嵌入对象可能只读出一部分，或完全漏掉 |
| PPTX | 按幻灯片顺序读取标题、文本框、列表、表格、演讲者备注、可以提取的图片链接、文件中保存的图表数据和 SmartArt 文字；检测到隐藏页或无文字页时会给出警告 | 文本框按页面位置排序，并排内容的顺序可能不准；不保留主题、动画和字符样式；图表只读取文件中已有的数据，SmartArt 无法还原图形关系 |
| HTML / URL | 从 `article`、`main` 或 `body` 中读取标题、段落、列表、链接、表格、引用、代码和图片说明；读取网址时会把相对链接补成完整链接 | 不保证准确识别网页正文；本地 HTML 中的相对链接保持原样；只有 CLI 会下载网页 |
| EPUB | 按书中定义的章节顺序读取标题、段落、列表等 HTML 内容 | 不处理 DRM、固定版式、图片、音视频和 CSS 布局 |
| IPYNB | 按顺序读取 Markdown 和代码单元格，并保留语言提示 | 不执行代码；忽略运行结果、交互控件、原始单元格和文档内图片 |

## 表格格式

| 格式 | 能读出什么 | 限制 |
| --- | --- | --- |
| XLSX | 工作表、数据区域、表头、表头前的说明、字符串、数字、布尔值、日期、文件中保存的公式结果、合并单元格左上角的值 | 默认每表 100 行；不计算公式，不保留样式和图表；一个工作表按一张表处理 |
| CSV / TSV | 表头、自动分隔符与常见编码、行列筛选 | 默认前 100 行；不判断数据类型；没有文件名时建议手动指定格式 |

## 图片和图表

能提取的图片和图表会在 Markdown 中留下 `spoor://` 链接：

- DOCX：`spoor://docx/part/word/media/...`
- PPTX：`spoor://pptx/part/ppt/media/...`
- PDF 图片：`spoor://pdf/obj/{id}/{gen}`
- PDF 整页矢量内容：`spoor://pdf/page/{n}`，提取后为 SVG

CLI 和各语言包都可以通过这些链接提取对应图片或文件。链接只能指向 spoor 已检查过的内容，不能用来读取压缩包中的任意文件。spoor 只提取文件，不识别图片里写了什么。

## 如何判断文件格式

检测大致按以下顺序进行：

1. PDF、ZIP、OLE/CFB 等文件头；
2. ZIP 内部结构，用于区分 DOCX、XLSX、PPTX 和 EPUB；
3. 文件名或 URL 扩展名；
4. 部分 MIME 类型。

`source_name` 很重要。没有扩展名时，spoor 可能认不出 CSV 和 IPYNB 等格式。通过标准输入读取 CSV 时，应使用 `--format csv`。

## 不支持的内容

- 旧版二进制 Office：`.doc`、`.xls`、`.ppt`
- 密码保护的 PDF 和 Office 文件
- OCR、视觉模型、语音或视频识别
- 宏、公式、脚本和 Notebook 代码执行
- 判断文档内容真假、识别提示注入，或判断某段文字是否足以支持结论

## 运行环境

| 环境 | 额外注意事项 |
| --- | --- |
| CLI | 读取网址时 30 秒超时；它不会处理网站爬虫规则，也不会登录网站或限制可访问的域名 |
| Rust / Python / Node.js | 在你的程序进程中运行；强制超时、内存限制和崩溃隔离需要独立进程或容器 |
| WASM | 会同时占用浏览器内存和 WASM 内存，传递字节与字符串时还可能复制数据 |

每个示例还有各自的注意事项，写在对应的 README 中。正式部署并处理来源不明的文件前，请同时阅读[安全说明](../SECURITY.md)。
